# Контроль заявок

Локальное браузерное приложение для ведения «Одиночек» и импорта заявок «Кит» из Excel.

## Файлы
- `index.html` — приложение.
- `sw.js` — service worker и офлайн-кэш.
- `manifest.webmanifest` — PWA manifest.
- `INSTALL-v1.txt` — заметки по установке и обновлению.

## Запуск
Откройте `index.html` в браузере. Для установки PWA и работы service worker требуется HTTPS или localhost.

## Импорт Excel
Импортируются строки начиная со строки 70. Используются столбцы D (`Номер заявки`), E (`Клиент`) и M (`Контейнер`) на листе `Лист1`.

## Важно
Данные хранятся локально в браузере. Регулярно скачивайте резервную копию через раздел «Данные». Очистка данных браузера может удалить локальные данные приложения.
