Обновление приложения «Контроль заявок» — версия 1.0

Состав
- index.html — новая версия интерфейса и логики заявок.
- sw.js — обновлённый service worker и версия кэша v10.

Перед обновлением
1. Открой текущую опубликованную версию приложения в том же браузере и на том же адресе, которым пользуешься обычно.
2. Открой «Данные» → «Скачать резервную копию».
3. Сохрани JSON-файл в безопасном месте.

Как обновить GitHub Pages
1. В корне репозитория TrueZell/zayavki открой index.html и замени его содержимое файлом index.html из этого комплекта.
2. В корне того же репозитория открой sw.js и замени его содержимое файлом sw.js из этого комплекта.
3. Не удаляй manifest.webmanifest, icon-192.png и icon-512.png — они остаются прежними.
4. Дождись завершения публикации GitHub Pages и заново открой приложение. Если видна старая версия, обнови страницу принудительно или закрой и снова открой приложение.

Сохранение данных
- Новая версия автоматически переносит заявки из старого localStorage, если новое хранилище ещё не создано.
- Для автоматического переноса открой приложение по тому же адресу и в том же браузере. Другой домен, путь или браузер означают отдельное хранилище.
- При переносе прежняя отметка «Сделано ЭПЭ» считается выполнением ЭПЭ Кл и ЭПЭ Суб. Старая отметка о букинге сохраняется в архивном поле резервных данных и не считается выполнением ЭР.
- Не используй «Восстановить из резервной копии», если нужно сохранить текущие записи: восстановление заменяет список заявок.

Импорт Excel
- Импорт читает лист «Лист1» (или первый лист, если название отличается), проверяет заголовки D «Номер заявки», E «Клиент», M «Контейнер» и обрабатывает строки, начиная со строки 70.
- Для чтения XLSX используется SheetJS с CDN. Первое открытие новой версии требует подключения к интернету, чтобы загрузить библиотеку; сервис-воркер сохраняет её для последующей работы офлайн, если браузер поддерживает кеширование сторонних ресурсов.
- Все данные заявок по-прежнему хранятся локально в браузере; серверное хранилище не используется.

Проверка перед рабочим импортом
- Сначала сделай резервную копию.
- В окне импорта проверь количество заявок, контейнеров и предупреждения.
- Только после этого нажми «Импортировать данные».
